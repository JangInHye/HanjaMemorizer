<주의 사항>
- 본인이 원하는 한자를 추가해서 암기할 수 있도록 하는 암기장 프로그램입니다.
- 일본어를 기본으로 생각해서 작성된 프로그램인 점 참고 부탁드립니다.
- 사전 검색은 한국어, 중국어, 일본어 중 고르면 네이버 사전으로 연결됩니다.
- 한자 사전 검색은 dict.json, 단어 사전 검색은 words_dict.json을 html과 같은 폴더에 올려야 동작합니다.
- 사전 데이터 출처: libhangul hanja.txt (BSD-3, Choe Hwanjin), KANJIDIC2 · JMdict (EDRDG, CC BY-SA 4.0)
- 모든 데이터는 언제든 날아갈 가능성이 있다는 점 참고 부탁드립니다.
- 단어 목록의 경우 내보내기/가져오기 기능이 있으니 백업하는 것을 권장드립니다.

<연락>
오류 및 기능 피드백은 디스코드로 부탁드립니다.
