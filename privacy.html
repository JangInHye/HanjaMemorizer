개요

한자 암기장(이하 "앱")은 개인이 만든 무료 학습 도구입니다. 앱에는 별도의 서버가 없으며, 개발자는 사용자의 학습 데이터나 개인정보를 수집·보관하지 않습니다.

앱이 다루는 정보

  • 학습 데이터: 사용자가 등록한 한자·단어, 시험 기록, 시험 제외 설정입니다. 사용자의 브라우저(localStorage)에 저장됩니다.
  • 구글 계정 이메일: 구글 로그인을 한 경우에만 조회합니다. 화면에 현재 계정을 표시하고 계정 변경을 감지하는 용도로만 쓰며, 사용자의 브라우저에 저장됩니다.
  • 구글 액세스 토큰: 로그인 시 발급되는 임시 권한입니다. 브라우저 메모리에만 보관되고 약 1시간 뒤 만료됩니다. 어디에도 저장하거나 전송하지 않습니다.

구글 계정 연동

구글 로그인은 선택 기능입니다. 로그인하면 앱은 drive.file 권한으로 사용자의 구글 드라이브에 HanjaMemorizer 스프레드시트를 만들고, 학습 데이터를 저장하거나 불러옵니다.

  • 이 권한으로는 앱이 만든 파일에만 접근할 수 있으며, 사용자의 다른 드라이브 파일은 보거나 수정할 수 없습니다.
  • 스프레드시트는 사용자 본인의 드라이브에 저장되며, 개발자는 이 파일에 접근할 수 없습니다.

앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

제3자 제공

앱은 사용자의 정보를 누구에게도 판매하거나 제공하지 않으며, 광고나 분석 도구를 사용하지 않습니다.

다만 앱을 이용하는 과정에서 다음 서비스가 각자의 정책에 따라 접속 정보(IP 주소 등)를 처리할 수 있습니다.

  • GitHub Pages: 앱과 사전 파일 호스팅 (GitHub 개인정보처리방침)
  • Google: 로그인과 스프레드시트 저장 (Google 개인정보처리방침)
  • 네이버 사전: 목록의 사전 검색 버튼을 눌렀을 때만 이동

데이터 삭제와 권한 철회

  • 앱 안에서 단어를 삭제하거나, 브라우저 설정에서 이 사이트의 데이터를 삭제하면 로컬 데이터가 지워집니다.
  • 구글 드라이브에서 HanjaMemorizer 스프레드시트를 삭제하면 저장된 데이터가 지워집니다.
  • 앱의 로그아웃 버튼을 누르거나 구글 계정 → 서드파티 앱 및 서비스에서 앱의 권한을 철회할 수 있습니다.
